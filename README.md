# Porfolio Asesor Ventas

Un portafolio web premium e interactivo diseñado para un asesor de ventas de vehículos usados. Cuenta con un diseño moderno en modo oscuro, catálogo de vehículos filtrable e integración completa con WhatsApp para la captura de consultas y opiniones reales.

## 🚀 Características

- **Diseño Premium**: Paleta de colores automotriz en modo oscuro, efectos de glassmorphism y micro-animaciones fluidas.
- **Catálogo de Autos**: Fichas técnicas completas con año, kilometraje, transmisión, combustible e informe de peritaje.
- **Filtro de Stock**: Búsqueda instantánea de vehículos por categorías (Todos, Sedanes, SUVs, Deportivos).
- **Testimonios WhatsApp**: Simulación interactiva de chats de WhatsApp reales con clientes satisfechos para generar confianza.
- **Acción Rápida de Conversión**:
  - Consulta individual por vehículo que pre-redacta un mensaje de WhatsApp.
  - Formulario de contacto general que recopila datos y los envía directamente a WhatsApp.
- **Optimizado**: HTML5 semántico, SEO básico y recursos gráficos de alta definición integrados de forma local.

## 📁 Estructura del Proyecto

```text
├── assets/             # Imágenes de stock e imágenes de perfil
├── index.html          # Página principal y estructura
├── styles.css          # Estilos CSS, animaciones y diseño responsivo
├── app.js              # Lógica interactiva y envío a WhatsApp
└── README.md           # Documentación del proyecto
```

## 🛠️ Instalación y Uso

1. Clona este repositorio o descarga los archivos.
2. Abre el archivo `index.html` en cualquier navegador web moderno haciendo doble clic sobre él.
3. (Opcional) Si deseas usar un servidor local para desarrollo rápido, puedes usar Python o Node:
   ```bash
   # Python
   python -m http.server 8000
   
   # Node
   npx http-server
   ```
